## What has actually been demonstrated?

### Takeaway
There is already a substantial physical system result, including a second noise-trained bitstream. A credible systems/implementation paper is plausible; a claim of a new diagnosis algorithm, universal severity generalization, or superior energy efficiency is not established by this evidence.

### Cited Findings
- Model identities must remain separate: the 2-layer float software baseline is 98.2171%; the deployed 1-layer SEQ256 float precursor is 97.6489%; INT10-input hardware is 97.7684%; raw-input on-chip normalization hardware is 97.7705%. Older SEQ1024 float/INT10 figures 97.55/97.11% belong to a historical variant, never deployed. The raw FPGA path performs per-window integer normalization, INT10 quantization, aggregation, Transformer, and class decision. ### Inferences
- Strongest paper narrative: fully integer on-chip preprocessing and tiny Transformer on resource-limited Zynq; physically bit-exact full-test verification; explicit response deadline and endurance; noise augmentation/vote accuracy-delay-resource tradeoff. This needs literature verification before novelty or venue promises.
- Repeating the same full dataset through hardware is valuable implementation verification but does not create independent classification evidence.

### Gaps
- No measured current/power/energy; vectorless Vivado W is explicitly an estimate. No real sensor stream, unseen machine/rig/dataset validation, or GUI hard-real-time guarantee. [Stated limits](../../docs/project_status.md#L231-L244).

### Inferences
- Cut claims of severity extrapolation, unseen-machine generalization,100%fault detection, general noise robustness, measured low energy, and end-to-end hard real time. Instead qualify operating range and board boundary.
- The existing k sweep and noise-trained model can support ablations if identified as exploratory. For new choices lock decision thresholds/k/metrics on validation before a fresh protocol; do not silently replace the canonical split.
- Purely adding more physical runs at intermediate SNR is lower scientific value than independent seeds, paired file-level uncertainty, and realistic corruption/transition protocols; software can do most of those after the board is returned.

### Gaps
- No evidence found for multi-seed training stability, cross-machine/dataset validation, a matched CNN/MLP/attention ablation with same latency/evidence budget, fresh confirmation split for new model decisions, or paired confidence intervals on noiseaug-vs-original and vote improvements. These are scoped absence findings, not proof nothing exists elsewhere.

## Which genuinely missing tests deserve board time?

### Takeaway
Prioritize tests that require physical hardware and produce independently useful evidence. Do not repeat completed noiseaug/0dB full tests because status prose is stale.

### Cited Findings
- Priority1: measured power/energy with inline DC meter or logging supply; idle, overlay loaded-idle, sustained raw/vote and noiseaug inference, same timing/workload boundaries, integrateWh/J per inference and subtract idle only if clearly labeled incremental. This is still explicitly open. [Open board work](../../docs/reports/paper_readiness_review_20261110.md#L195-L201).
- Priority2: collect existing8h run if it completes, then repeat across reboot/thermal steady state and preferably noiseaug bitstream. Record miss count/worst case/class-logit mismatches, temperature/load and exact hashes/config; current300k proof is original vote model under one RAM4096window workload. [Existing run pending](../../docs/reports/paper_readiness_review_20261110.md#L199-L201), [300k evidence](../../artifacts/results/raw_core_board_rt_20261111_141343/out/summary.json).
- Priority3: controlled true streaming ingress/transport verification at50kHz8channels, bounded buffers, stalls/backpressure/gaps, frame-id continuity, recovery and reboot. UART10k is already verified but separately; prepared RAM release currently stands in for sensorDMA. A real sensor is optional and not needed to preserve B.Sc.scope. [UART done](../../docs/project_status.md#L191-L200), [RAM stand-in](../../tools/board/fpga_rt_acceptance.py#L1-L17), [limitations](../../docs/project_status.md#L231-L244).
- Priority4: validation-locked causal voting with matched full stream, all transitions and missed transitions, varyk1/3/5/9/15, abrupt short faults and noisy transitions; then short physical spot checks at boundaries/register changes. Existing native/Python tests already randomly changek, include ties and invalidk, so do not claim dynamic-k logic itself is untested in software. [Native/software tests](../../tests/test_temporal_vote.py#L1-L55), [current physical k5](../../docs/reports/paper_readiness_review_20261110.md#L185-L193).

### Inferences
- Optional stronger scientific contribution: investigate amplitude-aware classification and safe channel-failure detection/abstention using training/validation only. Raw preprocessing already computes sigma, but feeding it to a model changes architecture/weights/quantization, needs user approval, and is not literally zero hardware cost. The current report proposes log-sigma but has not implemented it. [Proposal](../../docs/reports/paper_readiness_review_20261110.md#L40-L44), [open optional model work](../../docs/reports/paper_readiness_review_20261110.md#L202-L203).
- A generalization study with several seeds/held-out condition protocols and a same-budget baseline is a more defensible publication improvement than adding novelty-shaped complexity without addressing the74%failure. It can largely proceed without board access; quantize and physically verify only a validation-selected finalist.

### Gaps
- Need equipment confirmation for power measurement, actual completion/status of existing8h run (do not launch a competing overlay/job), sensor/source availability, and independently verified closest literature before promising journal level or novelty.
