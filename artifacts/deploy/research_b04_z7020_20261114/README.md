## Input (raw-input path)

- raw 24-bit ADC codes, one per little-endian int32 word; 8192 words per window, row-major [sample, channel] (word = sample*8 + channel), TLAST on word 8191
- Inside the FPGA: per-window per-channel integer z-score -> INT10 codes (+-511) -> 4:1 non-overlapping mean aggregation (1024 -> 256 tokens) inside transformer_top.
- Host-side normalisation: none (the host sends raw codes). `input_scale` in `config/model_manifest.json`
  is the INT10 code scale used inside the FPGA and is NOT applied by the host.

## Outputs

- `stream`: 4 int32 logits (S2MM, TLAST on logit 3)
- `pred_class`: AXI-Lite register: FPGA argmax, lowest index on ties; class map 0 normal, 1 imbalance, 2 misalignment, 3 bearing_fault
- `integrity_status`: integrity_status (AXI-Lite, metadata, never a class): bit0 input-buffer XOR signature (after ingress vs after projection), bit1 classifier tail evaluated twice and compared (time-multiplexed on ONE compute unit: detects transient upsets of one evaluation, not persistent/common-mode faults), bit2 projection accumulator outside its proven bound |acc+b| <= 719,316; bit3 per-row projection checksum (ABFT): sum_o acc[r][o] == sum_i x[r][i]*WSUM[i], exact integers
